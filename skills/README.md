# skills

Agent skills for working with raea, in the `SKILL.md` format agents such as Claude Code load.

- [`raea/`](raea/SKILL.md): write, render and check `@raea/motion` compositions, cut footage by its words, build
  small games, and drive void through its MCP server.
- [`raea-bevy/`](raea-bevy/SKILL.md): 3D scenes and games in `@raea/motion/3d`, drawn by Bevy, and how to extend
  that SDK.

The repository's Claude Code plugin (`.claude-plugin/`) installs them. void's agent learns from a longer library of
the same material in [`void/prompts/craft/`](../void/prompts/craft).
