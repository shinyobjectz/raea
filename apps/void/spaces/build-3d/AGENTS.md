# Build 3D (a void space)

This space is for building 3D worlds. The object on the stage is a 3D scene or game written with @raea/motion/3d
(Canvas3D, Mesh, lights, Model): load the raea-bevy skill before writing it. The outliner on the left lists the scene's
parts and the materials row across the top picks a material; both are panels in panels/, played live.
