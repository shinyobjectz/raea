# 3D

This is the short version. The 3D library is `bevy` (`raea craft bevy`): it routes to one file per topic (scene and
camera, lights, materials, meshes, animation, 3D games, models and pictures, bloom and fog, limits), each with a
working example. Read it as soon as a piece needs more than a turning shape under two lights.

## What to do

- Import the 3D components from `@raea/motion/3d` and put the scene in a `<Canvas3D>` inside your tree. The 3D is
  drawn under the page, so 2D parts (titles, captions) can sit over it in the same composition.
- Build the scene from:
  - `<PerspectiveCamera position fov>`: fov in degrees, 50 by default;
  - `<AmbientLight intensity color>` and `<DirectionalLight position intensity color>`, the latter shining from
    `position` towards the origin;
  - `<Mesh position rotation scale>`, holding one geometry and one `<MeshStandardMaterial color emissive
    emissiveIntensity metalness roughness>`. The geometries are `Box {args: [w, h, d]}`, `Sphere {args: [r]}`,
    `Plane {args: [w, h]}`, `Cylinder {args: [radiusTop, radiusBottom, height]}` and `Torus {args: [radius, tube]}`.
    For a cartoon look use `<MeshToonMaterial color steps={2} outline={{ width: 3 }}>` instead (hard light bands and
    an ink line; inside a `<Model>` it tones the model's own materials); `raea craft bevy/materials` has it.
- Animate a mesh by computing its `position`, `rotation` and `scale` from the frame, exactly as you would a 2D
  part. **Mesh rotation is in radians.**
- Prefer declaring a mesh's motion once: `<Mesh animate={{ y: track({ 0: 3, 18: 0 }, curve.spring({ damping: 12 })),
  rotateY: track({ 0: 0, 59: Math.PI }, "in-out-sine") }}>`. `x`, `y`, `z` set its position, `rotateX`, `rotateY`,
  `rotate` its rotation in radians, and `scale` its size. A material takes `animate` for `color`, `emissive`,
  `emissiveIntensity`, `opacity`, `metalness` and `roughness`, with colours blended in Oklab. The engine samples it
  from the frame (motion/animating has the tracks and curves).
- Model shapes the geometries can't make with Manifold solids: `manifold.box(w, h, d)`, `roundedBox`, `sphere`,
  `cylinder(r, h)` (along z), `cone`, `torus` and `text3d(text, size, depth, font, weight)`, combined with
  `.union()`, `.minus()`, `.intersect()` and `.hull()` and moved with `.move()`, `.rotate()` (**in degrees**) and
  `.scale()`. Pass the result as `<Mesh shape={solid}>`. You can also ask a solid about itself with `volume()`,
  `bounds()` and `slice(z)`.
- Colour materials from the brand kit. A material's `color` is a plain string handed to the 3D renderer, so read it
  from `brand.json` (`kit.palette.accent`) rather than typing a hex. The box that holds the `Canvas3D` has its
  background cleared to show the scene, and its colour becomes the scene's clear colour.
- For a scene with many moving things, keep them in an ECS world (`@raea/motion/ecs`) and draw it with `<Scene
  world>`. It draws the world's `mesh`, `camera`, `light` and `ambient` entities at the current frame (`motion/games`).

## Why

3D elements render as plain elements that carry their props, which raea's engine turns into camera, light and mesh
entities and draws with Bevy. A mesh's geometry reaches the renderer as a Manifold expression (`box(1, 2, 3)`), so a
modelled solid and a primitive travel the same way and render the same frames.

Manifold solids are made by the engine when it renders. Check a scene built from solids by rendering it and looking
at a still.

## Common mistakes

- `rotation={[0, 45, 0]}` meaning degrees. Mesh rotation is radians: `[0, Math.PI / 4, 0]`. (Solid's `.rotate()` is
  degrees, so the two differ.)
- A Mesh with two geometries or no material. Give it one of each.
- `metalness` or `roughness` outside [0, 1], `fov` outside (0, 180), or a scale of 0: they throw.
- `color="var(--brand-accent)"` on a material. The 3D renderer doesn't read CSS. Use the kit's hex from brand.json.
- A hex colour typed into a material. Read it from the kit.
- Rebuilding the same solid on every frame. Build it once at module level (in the engine) and move the Mesh.

## Example: a turning product block with the title over it

```tsx
import { AbsoluteFill, Composition, Easing, interpolate, registerRoot, useCurrentFrame, useVideoConfig } from "@raea/motion";
import { AmbientLight, Box, Canvas3D, DirectionalLight, Mesh, MeshStandardMaterial, PerspectiveCamera, Torus } from "@raea/motion/3d";
import { css } from "./styles.gen";
import kit from "./brand/brand.json";

const OUT = Easing.out(Easing.cubic);
const ACCENT = kit.palette.accent ?? kit.colors[0].hex;
const SURFACE = kit.palette.surface ?? kit.colors[0].hex;

export default function Turn() {
  const f = useCurrentFrame();
  const { fps } = useVideoConfig();
  const spin = (f / fps) * (Math.PI / 2); // a quarter turn a second
  const drop = interpolate(f, [0, 18], [3, 0], { easing: OUT, extrapolateLeft: "clamp", extrapolateRight: "clamp" });
  return (
    <AbsoluteFill style={{ backgroundColor: "var(--brand-background)" }}>
      <style>{css}</style>
      <AbsoluteFill>
        <Canvas3D>
          <PerspectiveCamera position={[0, 1.2, 6]} fov={40} />
          <AmbientLight intensity={0.4} />
          <DirectionalLight position={[3, 5, 4]} intensity={1.6} />
          <Mesh position={[0, drop, 0]} rotation={[0.2, spin, 0]}>
            <Box args={[1.6, 1.6, 1.6]} />
            <MeshStandardMaterial color={ACCENT} roughness={0.35} metalness={0.1} />
          </Mesh>
          <Mesh position={[0, -1.4, 0]} rotation={[Math.PI / 2, 0, 0]}>
            <Torus args={[1.8, 0.05]} />
            <MeshStandardMaterial color={SURFACE} emissive={ACCENT} emissiveIntensity={0.6} roughness={0.5} />
          </Mesh>
        </Canvas3D>
      </AbsoluteFill>
      <div style={{ position: "absolute", left: 90, right: 90, top: 300, textAlign: "center", fontFamily: "var(--brand-font-heading)", fontWeight: 800, fontSize: 120, lineHeight: 1, color: "var(--brand-text)" }}>
        Built to last
      </div>
    </AbsoluteFill>
  );
}

registerRoot(() => <Composition id="turn" component={Turn} width={1080} height={1920} fps={30} durationInFrames={120} />);
```

## Example: a modelled solid (engine only)

```tsx
import { AbsoluteFill, Composition, registerRoot, useCurrentFrame } from "@raea/motion";
import { AmbientLight, Canvas3D, DirectionalLight, Mesh, MeshStandardMaterial, PerspectiveCamera, manifold, type Solid } from "@raea/motion/3d";
import { css } from "./styles.gen";
import kit from "./brand/brand.json";

/** A rounded tile with a hole through it, built once (the engine holds it). */
let tile: Solid | null = null;
function getTile(): Solid {
  tile ??= manifold.roundedBox(2, 2, 0.4, 0.15).minus(manifold.cylinder(0.45, 1));
  return tile;
}

export default function Tile() {
  const f = useCurrentFrame();
  return (
    <AbsoluteFill style={{ backgroundColor: "var(--brand-background)" }}>
      <style>{css}</style>
      <Canvas3D>
        <PerspectiveCamera position={[0, 0, 6]} fov={40} />
        <AmbientLight intensity={0.5} />
        <DirectionalLight position={[2, 4, 5]} intensity={1.4} />
        <Mesh shape={getTile()} rotation={[0.3, f * 0.03, 0]}>
          <MeshStandardMaterial color={kit.palette.accent ?? kit.colors[0].hex} roughness={0.4} />
        </Mesh>
      </Canvas3D>
    </AbsoluteFill>
  );
}

registerRoot(() => <Composition id="tile" component={Tile} width={1080} height={1080} fps={30} durationInFrames={90} />);
```
