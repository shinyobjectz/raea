# Security Policy

## Supported Versions

Security fixes are provided for the latest release
and the main development branch.

## Reporting a Vulnerability

Please do not report security vulnerabilities through
public GitHub issues.

Instead, use GitHub's private vulnerability reporting
feature under the Security tab of this repository.

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential security impact
- A proof of concept, if available

## Response Timeline

We aim to acknowledge vulnerability reports within
5 business days.

Resolution timelines depend on severity and complexity.

## Coordinated Disclosure

Please allow maintainers reasonable time to investigate
and address vulnerabilities before public disclosure.

We will coordinate disclosure and credit researchers
when appropriate.
